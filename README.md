Esta pasta contém os arquivos, matriz de distâncias, de entrada gerados pelo programa gera1.py;
os arquivos de saída resultantes da execução do fnj_3.c-versão sequencial e do NV_02_1.py versão 
original do Neighbor-Joining em python.

Para executá-los temos as seguintes linhas de comando:

./fnj <arquivo_de_entrada> <fator_cabrigem> 
python NV_v02_1.py <arquivo_de_entrada> <fator_cabrigem> <arquivo_de_saida>

Contém ainda programas em python de exemplo para computar o Robinson-Foulds comparativos das árvores
resultantes, tendo a árvore NJ como referência.
